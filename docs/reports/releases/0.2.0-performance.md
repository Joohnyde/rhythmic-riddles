## Methodology

Authoritative release benchmarking is performed against the **downloaded CI-built RC artifact**, not a locally rebuilt binary. Before measurement, verify the downloaded artifact hash. Close avoidable noisy applications and keep power mode, workload, k6 version and application configuration comparable across repetitions.

Run the packaged startup/recovery harness and k6 scenarios at least **three comparable times**. Keep raw outputs long enough to investigate anomalies. Report median and representative range; do not cherry-pick the fastest run.

Latency values are descriptive for 0.2.0. Correctness/reliability failures are blocking; no tight p95/p99 performance budget is a shared-runner or release gate until controlled baselines justify one.

## Known limitations

- The authoritative 0.2.0 performance baseline is Linux-only; Windows 11 and Intel macOS are manual acceptance targets, not benchmark authorities.
- Shared GitHub-hosted runners are intentionally not used for tight latency gates.
- The harness validates a declared representative workload; it does not prove arbitrary scale.
- Additional UI-focused performance/a11y budgets belong to the 0.3.0 UI overhaul rather than Foundation 0.2.0.
- **PENDING:** add RC-specific limitations and anomalies.

## Reproduction commands

Record the exact commands used. Starting template:

```bash
# Integrity first
sha256sum <ci-built-rc-artifact>

# Packaged startup/recovery (at least three runs)
node scripts/perf/measure-startup.mjs \
  --app <unpacked-app-image-launcher> \
  --runs 3 \
  --version 0.2.0 \
  --build-code <build-code> \
  --git-sha <full-sha> \
  --artifact <ci-built-rc-artifact> \
  --power-mode '<mode>' \
  --background-services '<assumptions>' \
  --output perf/baselines/0.2.0-rc.N-startup.json

# Protocol smoke
BASE_URL=http://127.0.0.1:8080 k6 run perf/k6/smoke.js

# Multi-room/reconnect
ROOMS=<n> RECONNECTS=<n> BASE_URL=http://127.0.0.1:8080 \
  k6 run --summary-export perf/baselines/0.2.0-rc.N-websocket-run1.json \
  perf/k6/websocket-load.js

# Repeated lifecycle + supported action burst
ACTION_BURST=<n> \
ACTION_MESSAGE_JSON='<exact production Admin action JSON>' \
EXPECTED_ACTION_TYPE='<expected TV frame type>' \
BASE_URL=http://127.0.0.1:8080 \
  k6 run --summary-export perf/baselines/0.2.0-rc.N-lifecycle-run1.json \
  perf/k6/lifecycle.js
```
